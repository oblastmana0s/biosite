## 🚀 Hướng Dẫn Deploy Lên Cloudflare Pages

Dự án là **Static Web thuần (HTML/CSS/JS)** không cần cài đặt thư viện hay build build-step phức tạp. Bạn có thể deploy trong 1 phút:

1. Đăng nhập vào [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Chọn **Workers & Pages** > **Create application** > chọn tab **Pages**.
3. Chọn **Connect to Git** và kết nối tài khoản GitHub của bạn.
4. Chọn repository: **`oblastmana0s/biosite`**.
5. Cấu hình triển khai:
   - **Framework preset**: `None`
   - **Build command**: *(để trống)*
   - **Build output directory**: `/` *(hoặc để trống)*
6. Bấm **Save and Deploy**. Cloudflare sẽ cấp link truy cập dạng `https://biosite-xxx.pages.dev` miễn phí vĩnh viễn với CDN toàn cầu!
